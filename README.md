# PayPal Dispute AI

Aplikasi untuk membantu penyelesaikan dispute PayPal menggunakan AI.

## Cara Menjalankan

1. Buka file `index.html` di browser, atau
2. Deploy ke GitHub Pages (lihat pengaturan repo)

## Variabel Lingkungan

Salin `.env.example` menjadi `.env`, lalu isi:
- `NVIDIA_API_KEY` - kunci dari build.nvidia.com
- `PAYPAL_CLIENT_ID` - dari PayPal Developer Dashboard
- `PAYPAL_CLIENT_SECRET` - dari PayPal Developer Dashboard
